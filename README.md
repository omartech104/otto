# Otto 🤖
> **The AI task manager that's judging your life choices.**

A web app that rates your tasks by energy and impact, sorts them for you, and
gives you feedback you didn't ask for.

## 📌 Status
🚧 Work in progress. Backend first, AI last.

## ✨ Planned Features
- Create, view, edit, complete, and delete tasks
- AI-generated Energy Requirement (1-5 ⚡) and Impact Score (1-100%)
- Tasks sorted by impact
- Stale task highlighting (older than 3 days)
- Chat with Otto about your tasks
- AI performance reviews
- JSON export
